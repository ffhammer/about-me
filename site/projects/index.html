Happywhale - Whale and Dolphin ID

Probably the project I learned most from. At first, ConvNexts, Dynamic Margin ArcFace Loss, YOLO, etc. were intimidating. Kept coming back, learning more each time.

My first real deep learning project—competed in the Kaggle challenge for whale/dolphin ID based on fins. We finetuned CNNs with triplet loss, spent most time on preprocessing.

Together with two friends, we won both tracks of BBDC 2023 using extra weather/salinity data, advanced preprocessing, and models like LightGBM and XGBoost. Used autoencoders for weather features and lots of feature engineering.

Deep Pokis

For my deep learning course at NOVA Lisbon, the prof organized an internal challenge to classify Pokémon types from a custom dataset. I built my own dataset, trained a YOLO model for extraction, then fine-tuned deep CNNs and tried ArcFace. Ended up with the best performance in the class.

🇨🇭 Zürich WG Tracker

Probably one of my projects I use and enjoy the most right now.

To make the torturous task of finding a room in Zürich easier, I built this tool. Fetches listings from wgzimmer.ch, woko.ch, and students.ch, adds geo API data like bike and public transport commute times to ETH. Tracks and shows all offers. Also generates WG applications based on your writing, with interactive improvements.
